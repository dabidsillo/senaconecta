# LSB school MVP — dictionary, lessons, and capture slice

This work-unit snapshot runs the mobile-first Spanish dictionary shell, beginner category lessons, and labeled camera capture for future training/evaluation samples. It supports text lookup, safe result rendering, ordered playback controls for entries that later declare videos, clear missing-video states, text-only practice that resets when the page reloads, and explicit video + JSON downloads for each recorded clip.

The bundled entries are illustrative catalog labels, not validated Bolivian Sign Language claims. Camera capture does **not** translate signs, recognize movement, upload files, create accounts, use analytics, or store browser-persistent data.

## Run locally

1. From this directory run `python3 -m http.server 8000`.
2. Open `http://localhost:8000` in a modern browser.
3. Search examples such as `Hola estudiante`, `Gracias por el agua`, or `Familia y libro`.
4. Open “Lecciones”, pick a category, and answer the text-only practice prompts.
5. Open “Cámara”, allow camera access only if you choose to record, then download both the video and metadata JSON before closing or refreshing the page.

Avoid `file://` because browser JavaScript modules and camera APIs may be blocked. Camera access generally requires `localhost` or HTTPS. Recording blobs live in memory until replaced or the page closes.

## Catalog, videos, lessons, and capture

The dictionary and lessons read the same shared `src/catalog.mjs` starter catalog. Current entries intentionally have `videoPath: null`, so the UI shows “Video no disponible” instead of fabricating movement.

Beginner lessons are generated by `src/lessons.mjs` from categories with at least two catalog entries. Practice progress is held only in JavaScript memory for the current tab; refreshing or closing the page loses it by design.

The capture tool records at most 15 seconds per clip. The label is frozen when recording starts, then exported in the metadata JSON alongside timing, size, MIME type, catalog version, and explicit `upload: none` / temporary storage fields. A label is training data context only; it is not proof of recognition accuracy.

When a future reviewed recording exists, add the video asset in the deployed site and update the matching catalog entry with a real `videoPath`. Only change validation wording after actual review by qualified LSB creators or collaborators.

## Future slices

Automatic sign-to-text recognition requires multiple labeled examples of each moving sign, people/device variation, evaluation, and a separately implemented model or matching strategy. This MVP intentionally never returns a guessed translation.
